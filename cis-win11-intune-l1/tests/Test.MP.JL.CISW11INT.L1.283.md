#### Description

CIS Microsoft Intune for Windows 11 Benchmark, recommendation 82.11 (Level 1).

This test is always skipped: Set by script outside the Intune Settings Catalog. Check **Microsoft FTP Service (FTPSVC)** on the devices, or in the results of the script that sets it.

#### Remediation action

1. In the [Microsoft Intune admin center](https://intune.microsoft.com), go to **Devices** > **Scripts and remediations**.
2. Set **Microsoft FTP Service (FTPSVC)** to **Disabled or Not Installed** with a remediation or platform script, and assign it to your devices.
